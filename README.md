# קוראים עם החברים 📚

משחק ללימוד קריאה בעברית לכיתה א'. חיות מלמדות את התנועות שלב אחרי שלב:

1. 🐰 ארנבי: קמץ ופתח
2. 🦉 ינשופי: חיריק
3. 🐼 פנדי: חולם
4. 🐘 פילי: צירי וסגול
5. 🐢 צבי: שורוק וקובוץ
6. 🦁 אריק: שווא

בכל שלב יש היכרות עם התנועה, ושלושה תרגולים: שמע ובחר, קרא ובחר תמונה, ובנה מילה.

## איך משחקים
פותחים את קישור ה־GitHub Pages של הפרויקט בדפדפן, ומוסיפים אותו למסך הבית בטאבלט.
אחרי הפתיחה הראשונה המשחק עובד גם בלי אינטרנט. ההקראה משתמשת בקול העברי של המכשיר.

## קבצים
- `index.html`: המשחק כולו
- `manifest.webmanifest`, `sw.js`, `icon-*.png`: כדי שהמשחק יותקן כאפליקציה במסך הבית ויעבוד בלי אינטרנט
